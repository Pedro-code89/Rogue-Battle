## Rogue & Battle

# Sobre o Jogo

- Um jogo básico feito a partir da Engine Godot, criado para estudos e para aprimorar minhas habilidades com programação e desenvolvimento de jogos. A ideia é continuar evoluindo o projeto e, futuramente, desenvolver outros jogos com uma qualidade cada vez maior, podendo também publicar alguns deles na área de Game Dev.

# Linguagem

- GDScript

# Game

- Um assassino que busca batalhas cada vez mais difíceis. Em sua jornada, ele acaba encontrando inimigos completamente diferentes entre si, como um robô e um mago, cada um com suas próprias habilidades e motivos. O objetivo é simples: lutar, sobreviver e descobrir até onde consegue chegar.

# Mecânicas

- Sistema de combate
- Diferentes ataques
- Sistema de esquiva com dash
- Inimigos com comportamentos diferentes
- Sistema de vida e dano
- Hitbox e Hurtbox
- Animações
- Bosses
- Sistema de recarga da habilidade especial

# Desenvolvimento

- O projeto foi desenvolvido utilizando a Godot Engine e GDScript. Durante o desenvolvimento, foram estudados e aplicados conceitos de programação, lógica de jogos, máquinas de estados, animações, colisões e sistemas de combate.

# Objetivo

- O principal objetivo do projeto é aprender mais sobre desenvolvimento de jogos, colocando em prática conceitos de programação e criando sistemas que possam ser utilizados em projetos futuros.

# Futuro do Projeto
